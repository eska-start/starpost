# 별빛 우체부 루모 (Starpost Lumo) — 게임 기획서 v1.0

## 1. 한 줄 정의
떠다니는 섬 마을을 뛰어다니며 별빛을 모아 우체통에 배달하는 3D 수집 액션. 90초 안에 최대한 많이!

## 2. 재미의 원석 (Fun First)
- **주우면 기분 좋다**: 별빛은 자석처럼 끌려오고, 먹을 때마다 음계가 올라간다.
- **배달하면 터진다**: 우체통에 넣는 순간 별가루 파티 + 콤보 보너스.
- **위험하면 짜릿하다**: 몽실이를 피해 지름길로. 맞으면 별 3개가 흩어진다(주울 수 있음).

## 3. 코어 루프 (30초 안에 이해)
뛰어다닌다 → 별빛을 줍는다(자석) → 우체통에 배달한다 → 점수·콤보 → 시간 안에 반복 → 메달

## 4. 조작 (5세~성인, 키보드·터치 공통)
| 입력 | 동작 |
|---|---|
| 방향키/WASD·가상조이스틱 | 이동 (카메라 상대) |
| 스페이스·점프 버튼 | 점프 (2단 점프 아님) |
| R·버튼 | 재시작 |

- 카메라는 뒤따라오는 3인칭 고정. 회전 조작 없음(멀미·난도 방지).
- 이동 속도 7, 점프 힘 8, 중력 22. 섬 밖으로 떨어지면 우체통 앞으로 리스폰(-100점 없음, 시간만 손해).

## 5. 월드: 둥실섬 (1개 맵으로 완성)
- 지름 36의 원형 섬. 중앙 우체통(빨간 원통), 외곽 8개 별빛 스폰 지점.
- 점프 발판 3개(노란 패드, 밟으면 높이 점프), 몽실이 3마리(정찰 루트 순환).
- 별빛 최대 12개 유지, 먹으면 2초 후 다른 지점에 리스폰.

## 6. 규칙·수치 (확정)
- 제한 시간 90초.
- 별빛 1개 = 100점. 배달 시 소지 전부 정산 + 배달 콤보(연속 배달 간격 8초 이내면 ×2, ×3…).
- 몽실이 접촉: 소지 별 3개 흩뿌림 + 1.5초 무적 + 콤보 리셋.
- 메달: 1500점 동 / 2500점 은 / 3500점 금. 최고점·메달 저장.
- 몽실이 속도 2.2~3.0, 시야 없음(접촉 판정 반경 1.1). 5세도 피할 수 있게.

## 7. 적: 몽실이 (1종으로 깊게)
- 둥실둥실 통통 튀며 waypont 4점을 순환. 플레이어가 4 이내로 접근하면 1.5초간 돌진(속도 ×2).
- 돌진 후 2초 휴식(헉헉). 이 틈이 공략 포인트.

## 8. 진행·보상
- 1판 90초 arcarde. 메달·최고점 저장. 금메달 시 우체통 황금 변신(자랑 요소).
- (후속) 섬 2·밤 모드·2인 교대. 본 기획은 단일 완성판.

## 9. 아트·사운드 방향
- 파스텔 토이월드: 둥근 저폴리, 큰 눈 캐릭터, 낮 하늘 그라데이션.
- 효과음 전부 합성: 줍기(상승 음계), 배달(팡파레), 피격(쿵), 점프(뽕), 발판(슝).
- UI: 둥근 Jua 폰트, 큰 버튼, 이모지 최소(별·우체통만).

## 10. 기술·성능 목표
- Next.js + react-three-fiber, 물리 직접 구현(AABB·원 충돌).
- 60fps(저사양 노트북 기준), 드로우콜 100 이하, 그림자 1개 광원.
- 모바일 터치 대응(조이스틱+점프 버튼).

## 11. 완성 기준 (Definition of Done)
- [ ] 타이틀→플레이→결과 흐름 끊김 없음
- [ ] 90초 완주·메달·최고점 저장 동작
- [ ] 키보드·터치 모두 클리어 가능
- [ ] 떨어짐·피격·일시정지·재시작 전부 정상
- [ ] `npm run build` 통과

## 12. 리스크·대응
- 멀미 → 카메라 회전 없음·흔들림 최소로 해결.
- 난도 편차 → 몽실이 속도·별 리스폰은 상수로 묶어 한 곳에서 조정.
